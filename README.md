# Tabuada Inteligente

Programa em Java que gera a tabuada de 1 a 10 do número digitado.

## Funcionalidades
- Mostra a tabuada de 1 a 10 do número informado
- Indica se cada resultado é par ou ímpar
- Valida a entrada: números negativos mostram erro e pedem outro valor
- Encerra ao digitar 0

## Como executar
```bash
javac tabuadainteligente.java
java tabuadainteligente
```

## Tecnologias
Java
